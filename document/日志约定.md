## 事件约定表

| 事件名称    | 事件值                   | 含义                                                         |
| ----------- | ------------------------ | ------------------------------------------------------------ |
| eventName   | 事件名称                 | 比如AdInitStatus代表广告初始化状态                           |
| eventValue  | 事件值，和事件名称对应   | 比如false/true表示初始化状态                                 |
| eventInfo   | 事件详情                 | 可用来保存一些事件对应的信息，比如广告价值事件的收入，方便统计 |
| information | 其他信息，可为空         | 比如广告初始化报错信息                                       |
| inTime      | 插入数据库的时间。格式化 | 这个应该后端插入                                             |
| userId      | 用户ID                   | UUID生成即可                                                 |
| logId       | 日志ID                   | 使用数字前缀+UUID如00001-aaaa-bbbb，这样既可以判断数据是否有丢失的情况，也可根据字段排序 |
| versionCode | 当前APP版本号            | 如1.0.0等                                                    |
| packageName | 包名                     |                                                              |
| sdkCode     | 版本号                   |                                                              |
| androidId   | 安卓ID                   | 用来标志是否同一个用户（根据隐私政策来看，要是有限制就不要了） |
| OAID        | 国内的广告ID             | 貌似广告SDK都获取了的？(同上，隐私政策限制就算了)            |
| InstallTime | 安装时间                 |                                                              |

## 具体事件

  然后我想可以这样，下发一个json，里边配置一个字段，上传日志的等级，然后把日志分级，后续不需要用户上传不是很需要的日志就不上传了，第一版本或许可以根据前几次打开全部上传后续不上传等策略开控制

| Install         | 安装事件     | 必传，每个用户只上传一次，用来统计用户数量                   |
| --------------- | ------------ | ------------------------------------------------------------ |
| EnterSplash     | 进入启动界面 |                                                              |
| EnterMain       | 进入主页     | 约定，当天有这个事件的作为活跃用户。                         |
| EnterGame       | 进入游戏界面 | 以及进去一些其他有必要的界面都可以用Enter来传递，等级自定义，后续通过配置上传， |
| PlayCount       | 游戏次数     | 自定义，比如关卡数，游戏次数等等，                           |
| AdRequest       | 广告请求事件 |                                                              |
| AdLoaded        | 广告加载成功 | 这里可以再information里边传递加载成功时间等等                |
| AdFailure       | 广告请求失败 | info上传失败原因                                             |
| AdShow          | 广告展示     |                                                              |
| AdShowFailure   | 广告展示失败 | 上传失败原因                                                 |
| AdValue         | 广告价值     | 上传收益，统一单位                                           |
| Crash           | 崩溃         | info上传崩溃信息啥的                                         |
| AppBackgrounded | 进入后台     |                                                              |
| AppForegrounded | 回到前台     |                                                              |
